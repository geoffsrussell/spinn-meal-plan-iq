SPINN MEAL PLAN IQ - LIVE KROGER BUILD

1. Copy the CONTENTS of this folder into your local GitHub Desktop repository folder.
2. In GitHub Desktop, commit with: Live Kroger integration
3. Click Push origin.
4. Netlify will deploy automatically.
5. Keep your existing Netlify environment variables. Do not delete or rename them:
   KROGER_API_BASE
   KROGER_CLIENT_ID
   KROGER_CLIENT_SECRET
   KROGER_REDIRECT_URI
   SESSION_SECRET
6. After Netlify says Published, open https://freezeriq.netlify.app and hard refresh (Ctrl+F5).
7. Open Grocery Integration and test in this order:
   - Find stores
   - Select store
   - Generate shopping list
   - Match live products
   - Connect Fry's account
   - Add to Fry's cart

The old hard-coded Demo Mode has been removed.
